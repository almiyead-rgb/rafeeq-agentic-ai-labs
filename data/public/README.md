# Public data · البيانات العامة

**Status: schema and records pending. · الحالة: المخططات والسجلات قيد البناء.**

Only small, synthetic, versioned training datasets may be stored here. Planned files include orders, development tickets, scoped memory seeds, policy chunks, public security cases, and public evaluation cases.

يسمح هنا فقط ببيانات تدريبية صغيرة ومصطنعة وذات إصدار محدد. تشمل الملفات المخطط لها الطلبات، وتذاكر التطوير، وبذور الذاكرة المعزولة، ومقاطع السياسات، وحالات الأمن العامة، وحالات التقييم العامة.

No real customer, trainee, employee, order, payment, contact, or support data is allowed.

يُمنع وضع أي بيانات حقيقية لعميل أو متدرب أو موظف أو طلب أو دفعة أو جهة اتصال أو تذكرة دعم.
