# Utility scripts · السكربتات المساعدة

Foundation currently includes only `validate_foundation.py`. Runtime health checks, reference demos, and export safety checks will be added with the verified lab engine.

تتضمن مرحلة التأسيس حاليًا `validate_foundation.py` فقط. ستضاف فحوص بيئة التشغيل، والعروض المرجعية، وفحوص التصدير الآمن مع محرك اللاب بعد التحقق منه.

Scripts must default to offline, deterministic behavior and must never read or transmit credentials.

يجب أن تعمل السكربتات افتراضيًا دون اتصال وبسلوك حتمي، وألا تقرأ بيانات الدخول أو ترسلها.
