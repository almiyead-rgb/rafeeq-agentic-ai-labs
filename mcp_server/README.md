# Local MCP server · خادم MCP المحلي

**Status: implementation pending. · الحالة: التنفيذ قيد البناء.**

This folder is reserved for the local `stdio` Model Context Protocol server used by the cumulative lab. It must use simulated resources and tools, explicit schemas, bounded operations, and no paid external dependency.

هذا المجلد محجوز لخادم Model Context Protocol المحلي عبر `stdio` المستخدم في اللاب التراكمي. يجب أن يستخدم موارد وأدوات محاكية، ومخططات صريحة، وعمليات محدودة، ومن دون اعتماد خارجي مدفوع.
